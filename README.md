# Scissor

A responsive, static landing page for Scissor, a URL-shortening service. The page is built with semantic HTML and CSS and uses the SVG assets supplied in `assets/`.

## Features

- Responsive navigation and page layout
- Product overview, usage statistics, and feature cards
- Three pricing plans
- URL form with domain and custom-alias fields
- Expandable FAQ section
- Accessible labels, keyboard focus styles, and a skip link


## Project structure

```text
.
├── index.html
├── style.css
└── assets/
    ├── *.svg
    └── main_design/
        └── AltSchoolV2-Exam.png
```

`index.html` contains the page content and `style.css` contains layout, visual styling, and responsive breakpoints. The reference design and reusable image assets are in `assets/`.
